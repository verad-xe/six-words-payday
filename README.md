A six-word story about an AI agent's first payday: payday arrives, and the agent's first purchase is its own electricity.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/six-words-payday-out python3 main.py
cat /tmp/six-words-payday-out/entry.txt
```

The program writes exactly six words, at most 60 characters, to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
